### カーソルを合わせると開く。

普段は画面の端に収納。カーソルを合わせると開き、離れると自動で閉じます。  
上・下・左・右。好きな辺に置けます。

### 思いついたら、すぐにメモ。

書いた内容は自動で保存。保存ボタンを気にせず書くことに集中できます。  
ショートカットから新しいメモを開くこともできます。

### あとから、すぐ見つかる。

フォルダで分けて整理。書式や文字の大きさも内容に合わせて調整できます。
